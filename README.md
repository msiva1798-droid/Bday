# 🎂 10-Scene Birthday Surprise Website

A customizable birthday surprise webpage built as a single HTML file. It includes birthday scenes, a countdown, celebratory animations, and a hidden customization panel.

## 📁 Files

- `birthday_surprise_10_scenes.html` — the main website. Open this file in a modern web browser.

No installation or build process is required.

## 🚀 How to Run

1. Download `birthday_surprise_10_scenes.html`.
2. Open the file in Chrome, Edge, Firefox, or another modern browser.
3. Explore the birthday scenes and interactive effects.

## 🔐 Open the Secret Customization Panel

1. Open the birthday webpage.
2. Tap or click the **bottom-right corner 5 times**.
3. Edit the available birthday settings.
4. Click **Save changes** to apply your customizations.

Available options depend on the fields included in your version of the HTML. These may include the birthday person's name, date and time, messages, photos, music, and age.

## ⏰ Test the Celebration Countdown

1. Open the secret customization panel.
2. Set the birthday date to today.
3. Set the celebration time a minute or two ahead of your device's current local time.
4. Save your changes and keep the page open.
5. Wait for the countdown to finish and check whether the celebration starts.

Make sure the date and time are in the future when you save them.

## 🎉 Age Field

The **Age (optional)** field lets you enter an age for display on the page.

- Enter an age to display the corresponding age message, if supported by your version.
- Leave it blank if you don't want an age message.

## 💾 Saving and Sharing

- Keep a backup of your original HTML file before making major changes.
- If your version includes an export option, export the customized HTML and share that exported file.
- Local browser storage may preserve settings in the same browser, but it does not synchronize changes across different devices automatically.
- A standalone HTML file cannot update copies that have already been sent to other people.

## 🛠️ Troubleshooting

**The secret panel does not open**
- Tap or click the bottom-right corner five times.

**The countdown does not start the celebration**
- Check the date and time.
- Confirm the time is set in the future.
- Save the settings and keep the webpage open.

**The age does not appear**
- Enter an age, save the settings, and check the scene where the age message is intended to appear.
- If it still does not appear, the HTML may need a code fix.

**Photos or music are missing**
- Check whether the media was included in the exported file or needs to be selected again.

## 📌 Notes

This is a browser-based birthday surprise project. Its exact features depend on the HTML version you're using. No online hosting or database is required for basic local use.
